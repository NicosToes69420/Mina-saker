# Python Text Analyser 

**Hej!** Welcome to my Text Analyser project! I am a Computer Science student at **Linnæus University** , and this repository contains my comprehensive text analysis programme built in Python. (I did not write this, this is ai, I just wanted to make this readme thing at ANY cost) 





## Features



*   📂 **Smart File Loading:** Easily browse and select `.txt` files from the current directory.
*   🧠 **Memory Efficient:** Processes massive files line-by-line (`for line in file:`) without ever crashing your RAM! ⚡
*   🧮 **Basic Statistics:** Instantly calculates lines, words, paragraphs, and characters (with/without spaces).
*   🔤 **Word Analysis:** Finds the top 10 most common words, unique word counts, and average word lengths.
*   📏 **Sentence Analysis:** Spots the shortest and longest sentences, plus calculates average words per sentence.
*   🔠 **Character Analysis:** Breaks down letter frequencies, punctuation, and uppercase vs. lowercase distribution.
*   📊 **Stunning Visualisations:** Uses `Matplotlib` to generate bar charts 📊, pie charts 🥧, and histograms 📉 for all the data!
*   💾 **Export Results:** Saves a beautifully formatted summary report to a `.txt` file for easy reading later.
